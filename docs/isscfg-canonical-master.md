## 5. ATURAN INTEGRITAS & PRESERVASI ID (SAFETY CONSTRAINTS)

1. **ID 1–12 Data Lokal Terkunci**: ID 1 sampai dengan 12 tidak boleh di-truncate, di-delete, atau diubah primary key-nya karena menjadi referensi foreign key tabel operasional (`vessels`, `fishing_trips`, `fishing_efforts`, `catch_estimations`, `monthly_gear_stats`).
2. **Idempoten Tanpa Duplikasi**: Proses seeder menggunakan `updateOrCreate(['source' => 'FAO_ISSCFG', 'isscfg_code' => $code])` sehingga aman dijalankan berkali-kali tanpa menghasilkan duplikasi.
3. **Resolusi Hierarki Berjenjang**:
   - Tahap 1: Eksekusi Level 1 (parent_id = null)
   - Tahap 2: Eksekusi Level 2 (parent_id diambil dari map Level 1)
   - Tahap 3: Eksekusi Level 3 (parent_id diambil dari map Level 2)
   - Tahap 4: Update mapping 12 data lokal (parent_id diambil dari map Level 2/3)
4. **Isolasi Transaksi Database**: Seluruh proses dibungkus dalam `DB::transaction()` untuk memastikan konsistensi atomik.
